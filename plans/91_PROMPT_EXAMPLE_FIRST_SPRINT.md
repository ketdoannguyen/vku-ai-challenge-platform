# Example - Prompt to Start Sprint 00

Bạn có thể copy nguyên prompt này cho AI coding agent lần đầu:

---

Hãy làm theo `plans/90_MASTER_AI_CODING_PROMPT.md` và hoàn thành DUY NHẤT:

`plans/sprints/SPRINT_00_GUARDRAILS_AND_BOOTSTRAP.md`

Repo này có thể đã có một số file. Không xóa/ghi đè code hiện có nếu chưa inspect. Trước khi code:
- đọc tất cả master context/contract được prompt yêu cầu
- inspect repo và git status
- nếu stack hiện tại mâu thuẫn architecture, dừng và hỏi tôi

Ưu tiên code/tài liệu ngắn gọn, sạch, dễ debug. Không tạo boilerplate thừa. Kết thúc Sprint 00 thì cập nhật PROJECT_STATE và DỪNG, không tự làm Sprint 01.

---

Sau Sprint 00, những lần sau chỉ cần dùng prompt chung và thay sprint file, ví dụ:

`plans/sprints/SPRINT_01_LOCAL_STACK_AND_APP_SHELL.md`
